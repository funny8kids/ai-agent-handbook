# AI Agent 手册

> 一本系统化、持续更新的开源 AI Agent（人工智能智能体）手册：覆盖 AI 基础、LLM、Prompt 与推理、工具调用与协议、记忆与 RAG、规划、多智能体、框架生态、评估安全、工程化实践，以及论文、课程、开源项目、工具等精选资源。

## 如何使用本手册

- **入门读者**：从 [学习路线](00-index/learning-path.md) 开始，按 [01 → 02 → 03](00-index/learning-path.md) 的顺序打基础
- **开发者**：直接跳到 [05 工具调用与协议](05-tool-protocol/README.md)、[09 框架与生态](09-frameworks/README.md)、[11 工程化](11-engineering/README.md)
- **查资料**：用 [资源总表](00-index/resources-index.md) 和 [标签索引](00-index/tags.md) 快速定位
- **参与贡献**：阅读 [贡献指南](99-about/contributing.md)，用 [模板](14-templates/knowledge-template.md) 统一格式
