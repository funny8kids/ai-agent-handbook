# Awesome 列表

> 持续维护的资源合集，适合「扫货式」发现新项目。注意 Awesome 列表只负责「全」，不负责「精」——取舍仍靠自己判断。

## 推荐列表

| 列表 | 内容 | 链接 |
|---|---|---|
| awesome-ai-agents | Agent 项目大合集（E2B 维护） | <https://github.com/e2b-dev/awesome-ai-agents> |
| awesome-agents | 框架与工具精选（kyrolabs 维护） | <https://github.com/kyrolabs/awesome-agents> |
| awesome-mcp-servers | MCP Server 合集 | <https://github.com/punkpeye/awesome-mcp-servers> |
| awesome-llm | 开源 LLM 与部署工具 | <https://github.com/Hannibal046/Awesome-LLM> |
| awesome-rag | RAG 论文与工程 | <https://github.com/Danielskry/Awesome-RAG> |
| awesome-gpt4-agents-papers（等论文列表） | Agent 论文追踪 | GitHub 搜索 `awesome agent papers` |
| awesome-claude-code | Claude Code 生态（命令/子代理/工具） | <https://github.com/hesreallyhim/awesome-claude-code> |

## 使用建议

- 每月扫一次感兴趣的列表，新项目先看「最近提交时间」与「issue 响应速度」再决定是否投入
- 值得深读的及时建卡片页（用 [资源模板](../../14-templates/resource-template.md)）并登记到 [资源总表](../../00-index/resources-index.md)
