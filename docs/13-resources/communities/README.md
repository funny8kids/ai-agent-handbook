## 提问礼仪

- 先搜 issue/历史帖，附最小复现（版本、模型、prompt、报错全文）
- Agent 类问题贴完整 trace（脱敏后），比贴截图有用十倍
- 解决后回帖补结论，社区的健康靠每个人维护
- 别把「有没有现成方案」当成「帮我写完」——附上你已经试过的两条路，回复质量会差一个量级
