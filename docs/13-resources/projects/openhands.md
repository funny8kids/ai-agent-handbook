# 🔗 OpenHands

> **一句话**：全功能开源编程 Agent（原 OpenDevin）：SWE-bench 常客、可自部署的「AI 软件工程师」。

| 属性 | 内容 |
|---|---|
| 类型 | 开源项目（应用） |
| 链接 | <https://github.com/All-Hands-AI/OpenHands> |
| 来源 | All Hands AI |
| 协议 | MIT |
| 难度 | ⭐️⭐️ |
| 标签 | `#application` `#agent` |

## 🌟 推荐理由

- 开源编程 Agent 里功能最全：代码、浏览器、终端、Jupyter 全能力面
- SWE-bench Verified 上的开源标杆成绩，对比 Claude Code 类闭源产品的参照系
- 架构清晰（事件流 + Agent 技能 + 沙箱运行时），适合魔改自用

## 🧭 上手建议

1. Docker 部署跑通一个真实 issue 修复
2. 读它的事件流架构，与 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 的设计对照
3. 用 SWE-bench-lite 子集评估你的魔改效果（→ [SWE-bench](../benchmarks/swe-bench.md)）
