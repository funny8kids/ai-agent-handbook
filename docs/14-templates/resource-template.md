# 资源模板

> 向 [13 资源库](../13-resources/README.md) 添加论文、课程、项目、工具等资源时，使用下方卡片格式。
> 规范见 [风格指南](style-guide.md) 第三节体裁 D 与第五节引用规范。

## 使用说明

1. 复制资源卡片模板到对应分类页面（如 `13-resources/papers/react.md`）
2. 每个资源一张卡片、一个页面；同类资源在分类 `README.md` 中汇总
3. 高频优质资源可同步登记到 [资源总表](../00-index/resources-index.md)
4. 自检达标后，才把 `status` 从 `draft` 改为 `published`

## 资源卡片模板

````markdown
---
tags: [rag, paper]
type: resource
status: draft
updated: 2026-09-10
---

# 【资源名称】

> **一句话**：这个资源是什么、解决什么问题。

| 属性 | 内容 |
|---|---|
| 类型 | 论文 / 课程 / 开源项目 / 工具 / 数据集 / 基准测试 / 博客 / 社区 |
| 链接 | <https://example.com> |
| 来源/作者 | （作者、机构或维护者） |
| 发布/更新时间 | YYYY-MM |
| 许可 | MIT / Apache-2.0 / CC-BY-4.0 / 专有 |
| 活跃度 | star 数（标注观测日期，如"21.8 万，2026-09"）/ 最近提交 |
| 难度 | ⭐️ / ⭐️⭐️ / ⭐️⭐️⭐️ |
| 标签 | `#rag` `#mcp` `#multi-agent` |

## 推荐理由

写**具体**理由，避免"生态最大""体验好"这类空话：

- 它在你关心的某个具体维度上强在哪（给出可核验的事实，如"支持 X、实测延迟 Y"）
- 适用场景与不适用场景

## 上手建议

- 建议阅读/使用顺序
- 前置知识
- 最小可运行入口（命令、示例代码或文档锚点）

## 参考资料

- [官方文档 / 论文](https://example.com)

## 相关知识点

（反向链接：哪些知识点页面引用了这个资源）

- [RAG 基础](../../06-memory-rag/rag-basics.md)
````

## 双向链接规范

- **知识点 → 资源**：知识点页面底部「相关资源」链接到资源页
- **资源 → 知识点**：资源页面「相关知识点」反向链接回引用它的知识点页面
- 两端都要维护，保证读者可以从任意方向进入并跳转

## 标签规范

- 使用小写英文短标签：`llm`、`rag`、`mcp`、`multi-agent`、`evaluation`、`safety`、`framework`、`tooling`
- 每个资源 2–5 个标签，标签全集见 [标签索引](../00-index/tags.md)

## 收录标准

- 一手来源（论文 / 官方仓库 / 官方文档）优先
- 有活跃维护，或有历史里程碑价值
- 引用 star 数等易变数据时**必须标注观测日期**
