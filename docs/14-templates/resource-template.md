# 资源模板

> 向 [13 资源库](../13-resources/README.md) 添加论文、课程、项目、工具等资源时，使用下方卡片格式。

## 使用说明

1. 复制资源卡片模板到对应分类页面（如 `13-resources/papers/react.md`）
2. 每个资源一张卡片、一个页面；同类资源在分类 `README.md` 中汇总
3. 高频优质资源可同步登记到 [资源总表](../00-index/resources-index.md)

## 资源卡片模板

```markdown
# 【资源名称】

| 属性 | 内容 |
| --- | --- |
| 类型 | 论文 / 课程 / 开源项目 / 工具 / 数据集 / 基准测试 / 博客 / 社区 |
| 链接 | https://example.com |
| 来源/作者 | （作者、机构或维护者） |
| 发布/更新时间 | YYYY-MM |
| 标签 | `rag` `mcp` `multi-agent` |

## 一句话简介

这个资源是什么、解决什么问题。

## 推荐理由

为什么值得读 / 用：亮点、适用场景。

## 上手建议

- 建议阅读/使用顺序
- 前置知识

## 相关资源

- [相关资源](./相对路径.md)
```

## 标签规范

- 使用小写英文短标签：`llm`、`rag`、`mcp`、`multi-agent`、`evaluation`、`safety`、`framework`、`tooling`
- 每个资源 2–5 个标签，标签全集见 [标签索引](../00-index/tags.md)
