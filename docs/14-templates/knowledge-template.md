# 知识点模板

> 新增知识点页面时，复制下方模板使用，保持全书格式统一。

## 使用说明

1. 复制「模板正文」到新页面（如 `02-agent-basics/xxx.md`）
2. 在 `SUMMARY.md` 中登记该页面
3. 正文中的引用块、代码块按需保留或删除

## 模板正文

```markdown
# 【知识点名称】

> 一句话定义：用一句话说清楚这是什么。

## 详细说明

展开解释概念的核心思想、背景与动机。

## 工作原理 / 流程

（可选）用文字、列表或流程图说明运行机制。

## 代码示例

（可选）

# 最小可运行示例
​```

## 为什么重要

说明该知识点在 Agent 领域的位置与价值。

## 常见误区

- 误区一
- 误区二

## 相关知识点

- [相关概念](../相对路径.md)

## 参考资料

- [论文/博客/文档名称](https://example.com)
```

## 写作约定

- 文件名用英文小写 + 连字符（`what-is-agent.md`），标题用中文
- 每页聚焦一个知识点，宁短勿杂
- 代码示例必须可直接运行或接近可运行
- 参考资料附原文链接，方便溯源
